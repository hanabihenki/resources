Ray's Coding Vault


I am primarily a visual artist, but I have been learning to code for a while and I wanted to share what I have learned. This website was made to be used as a resource for HTML, CSS and Java Script (JS). HTML and CSS are technically not coding and instead are "markup" languages. However, for simplicity and consistency I will be calling it coding.

This website is intended for multiple websites so some resources may not work on all platforms. Artfight, Neocities, Tumblr, and Toyhouse all have different rules and limitations for what code is allowed to be used. I have tried to make my template and example code basic enough to be allowed for most websites but some mistakes may have been made. If you find code that doesn't work or an error, please message me on Bluesky or Twitter.
