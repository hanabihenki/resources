Welcome to Ray's Coding Vault

My main passion is in visual art. However, over the years I have gained knowledge in coding and web design. I created this site to share what I've learned and to provide an easily accessable resource, or vault, for everyone to use in their coding projects. I specialize in front-end design mainly using HTML, CSS and JS.

This website is intended for multiple websites so some resources may not work on all platforms. Artfight, Neocities, Tumblr, and Toyhouse all have different rules and limitations for what code is allowed to be used. I have tried to make my code simple enough to be allowed for most websites but some mistakes may have been made. If you find code that doesn't workor an error, please message me on Bluesky or Twitter.
