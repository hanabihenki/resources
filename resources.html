resources

A humble list of external webpages for learning and inspiration. Please note that some of these websites may use bright or flashing images. If I listed your website and you would like it removed or edited, please message me on Bluesky or Twitter.

Note: Toyhouse codes are most likely comptable with Art Fight. If you see a Toyhouse code you like, try it out on Art Fight and see if it works!


HTML

  • HTML5 Doctor
    Has all HTML tags listed out and explained.

  • Ultimate Coding Resource V1
    Extensive HTML resource showcasing the magic of div containers and how big certain pixel-sized objects are. Start here if you want to know what different tags in HTML do.

  • MDN - Creating the Content
    A beginner's guide on creating a website with HTML. More web development focused.

  • Codecademy - 29 HTML Snippets
    More web development focused.

  • Elithian Coding Resources
    Another extensive HTML resource. Showcases percentages and pixel-sized objects.

  • Code Beautify HTML Viewer
    Useful if your code is cluttered and difficult to read.

CSS

  • Buttons Masterpost HTML F2U
    Detailed resource on the magic of button styling in CSS.

  • CSS Reference
    A webpage where you can look up CSS properties and see what it does.

  • More developer focused CSS resource
    A reference to what CSS is, tutorials and examples of different CSS properties.

  • W3 Schools CSS
    A easy to understand and follow resource for CSS. This is marketed more towards beginners and has tutorials you can follow to learn more about CSS.
