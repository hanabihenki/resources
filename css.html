CSS

CSS changes how the page looks. It can be used to change text, borders, fonts, layout, colors, backgrounds, and almost anything you can think of! Property is the word used for CSS code.

CSS can be applied in two ways. The first way is by using a CSS class. A class is defined in a style tag on the same page as the HTML, or on a separate CSS file within the website. The second way is by using an inline style inside an HTML tag. The easiest way to use CSS is by using it within a tag.
Example of a HTML tag with no CSS: <p>
Example of a HTML tag with CSS: <p style="color: red;">

Because of these two different methods, two different code boxes are provided for each CSS property. The top one is for CSS classes. The bottom one is for inline styles. I recommend the inline style for beginners.
